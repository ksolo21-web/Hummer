# Independent authority facts v1

The Android preparation screen accepts UTF-8 canonical JSON through Android's document picker. Import is bounded to 1 MiB, 128 facts and nesting depth24. A session holds at most16 source files and128 facts; at most16 territory/mode sessions remain live. Receipts expire after15 monotonic minutes. Validation tickets expire after5 minutes and are single-use. Restart requires reimport and revalidation.

Envelope keys are exactly `schema`, `territory`, `mode`, `kb`, `facts`; schema is integer1, territory/mode/KB must exactly match the prepared baseline. Each fact has exactly `kind`, `item`, `value`, `verification`. Canonical encoding is the existing ExtendedValues canonical JSON serializer; whitespace, duplicate keys, alternate numeric encoding, trailing data and unknown keys are rejected. No payload role, trust flag or asserted hash is accepted.

Assignment categories: ROAD_LABEL (`text`), ROAD_PATH, ROAD_WORK, BUILDING_PATH and BUILDING_MEMBERS. All except ROAD_LABEL use the existing ExtendedValues JSON shape. Verification must be an empty object. The SHA256 computed over the entire actual file must equal the prepared baseline's current assignment authority hash and a locked Knowledge Base source hash. A reference hash alone cannot authorize assignment edits.

Inventory categories: LETTER_ADDRESS, PHONE_ADDRESS, PHONE_NUMBER, using existing ExtendedValues shapes. The actual file hash must be a preexisting eligible provenance source for that exact record and category. Phone facts additionally require telephone-use authorization. Address verification has `status`, `verifiedAt`, `boundary`, `boundarySha`, `conflicts`. Phone verification has `state`, `verifiedAt`, `bindingVerified`. All fields are sourced from the independent file, never copied from proposal flags. A verified-number record whose address changes requires an independently authorized PHONE_NUMBER binding fact, even if its number is unchanged. That specific dependency is the only allowed verification-only update.

Mixed files are accepted only if every fact passes its own authority check. Sources cannot overlap the same fact key. Use Remove imported authority facts before replacing them. Invalid imports preserve the previous receipt and candidate. Expired/revoked/superseded staging files are removed; prepared guards fail when their receipt is revoked or changed.

Import does not read either proposal journal. Reconciliation compares the complete candidate assembled from independent facts plus the original verified baseline against the exact changes in both journals. Fresh geometry providers, topology/work-side/overlap, building, inventory, and frozen production-adapter checks must pass. Geometry needing a new detail layout remains blocked until independently supported compatible layout is available.

This phase does not register new source authority or convert map PDFs into structured facts. Existing PDF-only sources remain blocked. Positive instrumentation fixtures use synthetic independently authored, pre-registered files. They do not establish real territory authority availability or authorize the six reserved Phase7 territories.
