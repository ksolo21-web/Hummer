# My Study Companion 0.14.1 theme finish

This branch is a theme-only finish for the already repaired 0.14.1 build.

- Google sign-in remains unchanged.
- All 23 permanent themes plus Automatic remain available.
- The 13 approved illustrated themes use Kaleb's approved concept compositions as the visual contract.
- Phone, Fold/tablet, Wear OS, widgets and PWA share the same static visual identity.
- Illustrated themes use polished translucent cards, refined spacing, strong contrast and native quick actions.
- No live, animated, video, GIF, Lottie, parallax, particle or infinite-motion theme is permitted.
- CI must reconstruct, verify and compile the exact branch head before release artifacts are accepted.
