Authentication boundary
-----------------------
The workflow currently receives empty KREATIV Firebase/OAuth variables. The debug
APK therefore keeps Google sign-in disabled. Google sign-in requires a registered
com.kreativstudio.app Firebase Android client, matching SHA-1/SHA-256 signing
fingerprints, the Google web client ID, and a build signed with that registered
KREATIV certificate.
