# HAVENLINE Production Validation Scope

This branch is a clean rebuild and does not reuse the rejected open-plane game foundation.

The validation build must visibly prove:

- close orthographic/isometric presentation;
- smooth original stylized characters rather than block people;
- a dense bounded frozen outpost centered on the furnace;
- correct screen-relative joystick movement;
- hard perimeter collision and automatic fall recovery;
- automatic gathering, visible carrying, and furnace delivery;
- furnace progression and expanding warmth;
- survivor helper automation and defensive wolf pressure;
- a compact mobile HUD;
- an exact rendered validation frame before Android export.

The draft PR must remain unmerged until the rendered frame and exact APK are reviewed.
